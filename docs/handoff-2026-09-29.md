Causa: `_INDEX_CACHE` comparte `AstIndex` entre threads. **X2.3a quedó mal calibrado** — la decisión de "aceptar el límite y documentarlo" rompía la tool en uso normal.
   - **Fix** (`af9d1ba`): `check_same_thread=False` + `RLock`. Ojo: `threadsafety=3` del módulo C **no protege el wrapper Python**. Sin `RLock`, dos threads llamando `.cursor()` a la vez dan `InterfaceError('bad parameter or other API misuse')`.

   - Bug real detectado al pasar el test cross-thread: `search()` ejecutaba la query **DOS veces**, la segunda fuera del lock.

2. **ALTO** `python` vs `python3`. Cada fase gastaba 2 tool calls (falla, reintenta con `python3`). ~25 turnos perdidos.
   - **Fix** (`45baf3f`): `ShellClient.execute` normaliza `python` → `python3` en `parts[0]` antes de `Popen`.

3. **MEDIO** Regla 2 del prompt no cubría `insertar_en_archivo`/`editar_archivo`.
   - **Fix** (`d9f8ca3`): regla 2 renombrada a "LECTURA OBLIGATORIA ANTES DE MODIFICAR", nombra las 3 tools.

4. **BAJO** `editar_archivo` con mensaje pobre.
   - **Fix** (`fb60675`): mensaje incluye firma esperada.

5. **BAJO** Tracker contaba tracebacks multi-línea como N errores.

## REGLAS DE PROCESO

1. **Un paso por bloque**. Tests y commits en bloques separados con `PARA. Pégame la salida`.
2. `str.count(old) == 1` obligatorio en scripts de patch.
3. Tras cada apply: `git diff --stat` **antes** de `pytest`.
4. `_ChatContext` (dataclass): campos nuevos con default al final.
5. Tests del controller con `__new__` + asignación manual: `getattr` defensivo.
6. Editable install + carpeta movida = `.pth` huérfano que rompe Python.
7. **Antes de tocar `httpx.post`/`httpx.get`/`httpx.AsyncClient`**: 7 archivos de test los mockean.
8. **NUNCA triple-backtick dentro de strings Python en heredocs.**
9. **Un `cat > file << EOF` por bloque**, o `/tmp/apply_*.py` atómico.
10. **Tests con `AstIndex(root)` sin `db_path`**: fixture autouse monkeypatch `CACHE_DIR`.
11. **Tests que referencian `_SCHEMA_VERSION`**: importar la constante.
12. **ruff con `.ruff.toml`**: `select = [E,F,W,I,UP,B,SIM,C4,RET,RUF]`.
13. **mypy lee `pyproject.toml`**: `files = ["core","ui","plugins"]`.
14. **Auditoría externa usa `P#N`**: mantener nomenclatura en commits.
15. **Strings con `\n` dentro de `/tmp/apply_*.py`** → usar `r'''...'''` (raw).
16. **Tests con Qt que inicializan widgets** → verificar aislado antes de commitear.
17. **Quotes anidados en literales vía `write_text()`** → delimitador opuesto o payload simple.
18. **Patch que reemplaza `old` por `new` donde `old` es prefijo de `new`** → `str.count(old) == 1` NO protege. Anclar `old` con línea posterior.
19. **Endurecer una función** (añadir rechazos) → revisar **también los casos positivos** del test.
20. **Markdown del handoff** → escribir con `cat > file << 'MDEOF'` en chunks (los triple-backticks anidados rompen el pegado).
21. **SQLite compartido entre threads**: `check_same_thread=False` **NO basta**. El wrapper Python necesita `RLock` propio. `threadsafety=3` es del módulo C, no de `Connection`.
22. **Módulos con `RLock`**: exponer helpers `cursor()` / `commit()` que tomen el lock. Si otros módulos acceden a `.con`, migrarlos.
