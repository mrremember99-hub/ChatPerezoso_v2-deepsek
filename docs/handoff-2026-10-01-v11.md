## Bugs del modelo (documentados, no accionables desde harness)

**1. `validate_images` mal usado.**
`validate_images` devuelve `(bool, str)`, no lanza. El modelo lo
envolvió en `try/except` — la validación nunca se aplica.

**2. `_apply_transform` diverge de F17.**
F17 pidió transformaciones sobre las franjas, dentro de
`process_interlace`. F19 las aplicó sobre imágenes enteras en
`gui.py`. Los params `transform`/`param` de `core_processor`
quedan como código muerto.

**3. Tool hallucination `python`.**
El phase spec dice `python -m py_compile gui.py`. Con contexto
crecido, el modelo interpreta "python" como tool. Falla, se
autocorrige a `ejecutar_comando` (~10 intentos perdidos).
